# Адміністративна панель - Статистика відвідувань

## Що було додано:

### 1. База даних
- **Нова таблиця**: `site_statistics` для зберігання статистики відвідувань
- **Міграція**: `V4__add_site_statistics.sql`
- Поля:
  - `id` - унікальний ідентифікатор
  - `visit_date` - дата відвідування (унікальна)
  - `daily_visits` - кількість відвідувань за добу
  - `total_visits` - загальна кількість відвідувань

### 2. Domain & Repository
- **SiteStatistics** - entity для статистики
- **SiteStatisticsRepository** - репозиторій з методами:
  - `findByVisitDate()` - пошук статистики за датою
  - `getTotalVisitsAllTime()` - загальна кількість відвідувань
  - `incrementVisitsForDate()` - збільшення лічильника

### 3. Service Layer
- **SiteStatisticsService** - інтерфейс сервісу
- **SiteStatisticsServiceImpl** - реалізація з методами:
  - `recordVisit()` - запис нового відвідування
  - `getTotalVisits()` - отримання загальної кількості
  - `getDailyVisits()` - отримання денної кількості
  - `getTodayStatistics()` - отримання статистики за сьогодні

### 4. Controller
- **AdminController** - контролер для адмін-панелі
- Маршрут: `/admin`
- Доступ: тільки для користувачів з роллю `ROLE_ADMIN`
- Використовує `@PreAuthorize("hasRole('ADMIN')")`

### 5. View
- **admin.html** - HTML шаблон адмін-панелі
- Відображає:
  - Лічильник відвідувань за весь час
  - Лічильник відвідувань за сьогодні
  - Стильний дизайн з градієнтами
  - Інформаційну довідку

### 6. Interceptor
- **VisitCounterInterceptor** - перехоплювач для підрахунку відвідувань
- Автоматично записує відвідування при кожному запиті
- Записує тільки одне відвідування на сесію
- Виключає статичні ресурси (CSS, JS, зображення)

### 7. Configuration
- **WebMvcConfig** - конфігурація MVC
- Реєстрація interceptor для всіх URL крім статичних ресурсів

### 8. Menu
- Додано посилання "📊 Адмін панель" в навігаційне меню
- Відображається тільки для користувачів з роллю `ROLE_ADMIN`
- Використовує Thymeleaf Security: `sec:authorize="hasRole('ADMIN')"`

## Як використовувати:

1. Запустіть додаток
2. Увійдіть як користувач з роллю `ROLE_ADMIN`
3. У меню з'явиться посилання "📊 Адмін панель"
4. Перейдіть на `/admin` для перегляду статистики

## Технічні деталі:

- Статистика зберігається в PostgreSQL
- Кожна унікальна сесія рахується як одне відвідування
- Щодня створюється новий запис з обнуленим денним лічильником
- Загальний лічильник ніколи не обнуляється
- Використовується транзакційна обробка для забезпечення цілісності даних

## Безпека:

- Доступ до адмін-панелі захищений Spring Security
- Тільки користувачі з `ROLE_ADMIN` можуть переглядати статистику
- Перехоплювач працює незалежно від авторизації користувача
